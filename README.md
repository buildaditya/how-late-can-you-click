# How Late Can You Click?

A tiny browser game where you try to click a button as late as possible without missing it.

That’s it.

### How to play
1. Press Start
2. Wait
3. Click as late as you dare
4. Try not to miss

Seven rounds. Getting closer is better. Missing is worse.

### Play
Just open `index.html` or visit the live version if it’s deployed.

### Stack
One HTML file. No frameworks. No build step. No nonsense.
